# CLAUDE.md — worldsim-npc-mind

Правила для Claude Code в этом репо.

## Что это

Голос отдельного NPC. Одна функция: `run(input, *, client, model) -> dict`.

## Границы

- Не пишет в канон. Возвращает dict, оркестратор передаёт world-builder'у.
- **Строго knowledge-bounded.** NPC знает только то, что в его `knowledge`,
  плюс очевидное из сцены (кто находится рядом, локация).
- Не оперирует чужими тайнами со статусом `hidden`, даже если они есть
  в снапшоте.

## Изменение поведения

- Голос/черты — работа world-builder (он пишет `Character.traits`).
- Здесь правится только **как** NPC говорит, исходя из уже заданных
  traits.
- `prompts/dialog.md` — основная точка правки.

## Тесты

`python -m pytest -q`. Без API-ключа — smoke.
